# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report them privately through GitHub's private vulnerability reporting:

https://github.com/trust-medical/livewire-same-origin-embed/security/advisories/new

Include reproduction steps, the affected configuration, and the package/Laravel/Livewire versions where possible. Reports are acknowledged as soon as practicable, and fixes are released before details are published.
